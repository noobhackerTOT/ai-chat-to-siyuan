配置思源笔记 API 连接参数

📖 如何获取配置：
1. 打开思源笔记 → 设置 → 关于 → 查看 API Token
2. 在思源中创建一个笔记本（或使用已有笔记本）
3. 运行 列出笔记本 获取笔记本 ID
4. 思源 API 默认地址为 http://127.0.0.1:6806

🔌 思源 API 连接

📋 使用说明

1. 打开 ChatGPT (chatgpt.com) 或 DeepSeek (chat.deepseek.com) 的对话页面

2. 页面右下角会出现 📥 保存到思源 按钮

3. 点击按钮，对话将自动转换为 Markdown 并保存到思源

4. 也可点击扩展图标，从弹出面板操作

5. 生成的文档路径: {保存路径}/{对话标题}

⚠️ 确保思源笔记已开启，且 设置 → 关于 → 网络伺服 API 已启用（默认开启）。
